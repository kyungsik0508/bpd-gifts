# Choose your gift

Berlin Photobook Distribution gift selection page.

Publish with GitHub Pages from the main branch root. Set the custom domain to gifts.berlinphotobookdistribution.de, then configure its DNS CNAME to kyungsik0508.github.io. Enable HTTPS once the certificate is ready.

The self-contained index.html includes the product photos and three-item selection interface. No checkout or order is submitted by this page.
